# Perícia de Engenharia – Benfeitorias no Porto do Recife

**Processo nº 0803444-36.2015.4.05.8300** · Procedimento Comum Cível · 21ª Vara Federal/PE (TRF5)
Autora: CONAB · Ré: Porto do Recife S/A
Perito do Juízo: Dr. Erison Rosa de Oliveira Barros – CREA-PE 38236

🌐 Página do projeto: https://erisonbarros.github.io/pericia-porto-recife/

## Objeto

Perícia judicial **indireta** para avaliação das benfeitorias e instalações do antigo Entreposto Federal de Pesca do Recife (Cais de Santa Rita), demolido para implantação de empreendimento hoteleiro. Pontos controvertidos (decisão de 27/08/2026, ID 183149730):

1. Adequação metodológica do Laudo CEF nº 7137.7137.049526/2012 (método involutivo, R$ 6.523.000,00);
2. Melhor forma de definir o valor econômico das benfeitorias (involutivo × comparativo direto de dados de mercado – ABNT NBR 14653).

## Publicação no GitHub Pages

1. Conteúdo publicado na raiz da branch `main` de https://github.com/ErisonBarros/pericia-porto-recife.
2. No GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. Após 1–2 minutos, a página estará em `https://erisonbarros.github.io/pericia-porto-recife/`.
